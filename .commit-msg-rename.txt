refactor: 包改名 siyuan-devkit，命令收敛为单一 syt

## 命名

之前叫 vite-plugin-siyuan，两个问题：
1. 暗示是思源官方包（其实不是）
2. vite-plugin-* 前缀语义是「包里主要就是一个 Vite 插件」，
   但我们实际有 68 个导出 API、29 个源文件、6 个 bin，
   Vite 插件只占 plugin/ 3 个文件

改成 siyuan-devkit：
- 无 scope、中性，将来被官方收编不用改包名
  （只需 GitHub 仓库 transfer + npm owner add）
- 查证 npm 上 siyuan-devkit 空闲；@siyuan-community 是别人的组织，不冒用
- devkit vs devtools：npm 上 devtools 指浏览器调试面板/CDP
  （Vue/React/Chrome DevTools），devkit 指框架扩展工具
  （Angular DevKit / Nx Devkit），我们属于后者

## 命令收敛

之前 6 个长命令（siyuan-devtools / siyuan-dev / siyuan-link /
siyuan-measure / siyuan-open / siyuan-watch）其实是同一套子命令的
重复入口，且 siyuan-devtools 16 字符带连字符不好敲。

现在只留 syt 一个 bin，所有能力走子命令：
  syt dev / syt measure tokens / syt measure audit / syt link / syt open / syt watch

查证 syt 这个 npm 包名虽被占但无 bin，命令名不冲突。
社区短命令惯例：gh / ng / nest / fd / rg（包名与 bin 名解耦）。

删掉其余 5 个 bin 文件与所有文档中的等价命令说明。
父项目 scripts、skill 29 处、README、docs 全部同步。

顺手修了两处文档死路径（src/targets.ts -> src/core/targets.ts，
src/actions.ts -> src/core/actions.ts）和一个残留的临时脚本。
